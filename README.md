Machine Learning project to predict food delivery time using machine learning based on factors such as distance, traffic, weather conditions, delivery partner details, and order information. 
Technologies Used: Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, XGBoost, and Streamlit. 
Model: XGBoost Regressor
Key Steps: Data Preprocessing, EDA, Feature Engineering, Hyperparameter Tuning, Model Evaluation, and Streamlit Web Application Development.
